# HimikiHamaka — проверка (этап 0)

Небольшая страница-приложение, чтобы до создания настоящего приложения домашней описи
HimikiHamaka проверить на своих устройствах (iPhone и Mac) самые рискованные возможности:
камеру и распознавание QR, установку на экран «Домой», работу без сети, диктовку,
хранилище и печать наклеек.

**Адрес:** https://krenk-ai-os.github.io/himikihamaka-check/

## Что проверяется

- **Устройство** — версия iOS и Safari, запуск с экрана «Домой», экран, сеть, язык.
- **Установка** — добавление на экран «Домой» и открытие без сети (авиарежим).
- **Камера и QR** — выбор задней камеры (в том числе «двойной» и «тройной»), фокус, зум,
  фонарик, непрерывное распознавание QR (zxing-cpp в WebAssembly, запасной вариант — jsQR),
  серия из 20 сканов (цель — не менее 95 % за 1,5 с на 10–20 см при одной лампочке),
  повторный запрос разрешения на камеру после перезапуска.
- **Диктовка** — голосовой ввод iOS без сети и разбор списка вещей
  («шурупы 3 штуки», «2,5 метра кабеля») и номера наклейки («аш 42» → H0042).
- **Хранилище** — постоянное хранение, квота, IndexedDB (1000 записей), localStorage.
- **Печать наклеек** (на Mac) — пробные наклейки 58×40 или 30×20 мм для термопринтера
  XP-365B (203 dpi); номера с буквой T, чтобы не путать с настоящими H-номерами.
- **Итог** — все результаты одним текстом и в JSON.

## Как пользоваться

1. Откройте адрес в Safari на iPhone.
2. В разделе «Установка» добавьте страницу на экран «Домой» и дальше работайте
   в установленном приложении «Проверка».
3. Пройдите разделы по порядку. В конце откройте «Итог», нажмите
   «Скопировать результаты» и вставьте текст в чат.

## Приватность

- Страница **ничего никуда не отправляет**: нет аналитики, счётчиков и запросов к чужим сайтам.
- Все библиотеки лежат в репозитории (папка `vendor/`), из интернета во время работы ничего
  не загружается.
- Результаты проверок хранятся **только на этом устройстве** (localStorage) и попадают в чат,
  только если вы сами скопируете и вставите их. Кнопка «Сбросить результаты» в разделе «Итог»
  их удаляет.

## Состав

| Файл / папка | Назначение |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | страница и переключение разделов |
| `js/` | модули: камера и серия сканов, декодер в Web Worker, разбор диктовки, хранилище, печать, итог |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на экран «Домой» и работа без сети |
| `vendor/` | сторонние библиотеки с лицензиями; происхождение и сборка — в `vendor/VENDOR.txt` |

Сборка не нужна — это обычные статические файлы. Локально можно открыть так:

```
python3 -m http.server 8000
```

и зайти на http://localhost:8000/ (камера работает только на localhost или по https).

Публикация: GitHub Pages, ветка `main`, корень репозитория. Все пути в коде относительные,
поэтому сайт работает по адресу с подкаталогом `/himikihamaka-check/`.

## Обновление

После любого изменения файлов увеличьте `VERSION` в `sw.js` (и `APP_VERSION` в `js/state.js`):
установленное приложение берёт файлы из офлайн-кэша и без новой версии кэша изменений не увидит.
